# ontoterrorista

Página experimental en pixel art: un tren baja por la colina con humo, la pantalla se quiebra y aparece una mini descripción de mis intereses filosóficos.

- `index.html`: cinemática en canvas (sin dependencias), sonido procedural con WebAudio.
- `src/build_assets.py`: saca el fondo, el tren y los cuadros del humo de la imagen de referencia (`src/ref.webp`).
- `src/humo.pxo`: proyecto de Pixelorama con los 8 cuadros del humo; la hoja `humo.png` se exportó con la CLI de Pixelorama.
